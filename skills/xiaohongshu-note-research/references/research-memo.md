# Writing the research memo

The memo is the deliverable. It is written from notes that were looked up or pasted.
It is never written from typical category copy.

## Four blocks

1. **Title patterns.** Recurring shapes in the titles in hand: number, how-to,
   mistake, before-and-after, or a claim. Quote the titles. Do not invent a pattern
   from what this category usually uses.
2. **Structure.** How the notes actually move: hook, proof, steps, close. Keep this a
   read of the bodies in hand.
3. **Verbatim comments.** Keep the audience's wording. If no comment was looked up or
   pasted, say comments are missing rather than inventing one.
4. **Followable angles.** Openings the user can take, each tied to a title, a
   structure move, or a comment that prompted it. An optional one copy draft stays
   research-shaped: it shows one angle in draft form, it is not a production pack.

One revision of the wording is free. Regenerating the memo from the same notes is
free. A new lookup is not.

## Provenance

- A figure or line read from a lookup is marked as looked up, with the date it was
  read.
- A figure or line the user supplied stays marked as supplied.
- A missing figure is stated as missing. It is never estimated, interpolated, or
  carried in from what similar notes usually look like.
- Why a note performed well remains inference. Mark it as inference, give the
  evidence, and say what would confirm it.
