# Next step after a poster

Follow [offering one next step](next-step-offers.md). Check these in order and
offer the first that fits; offer nothing when neither fits.

1. **The user on camera, in another Skill.** The poster promotes the user
   personally or their own business, and the user has said they want to
   appear or speak about it themselves. Point to Founder IP Avatar Studio:
   one authorized photo of the user and a short script become a talking video
   in the user's own voice. They prepare a front-facing photo and a short
   voice sample. Install message, in the user's language:

   ```text
   请安装 数字人分身·创始人口播；需要登录授权时告诉我：https://beatra.ai/skills/founder-ip-avatar-studio/install.md
   Install Founder IP Avatar Studio and tell me when I need to sign in: https://beatra.ai/skills/founder-ip-avatar-studio/install.md
   ```

2. **A motion version of this poster, in place (the usual step).** The poster
   will be seen on a screen: WeChat Moments or Channels, Douyin, Xiaohongshu,
   a group chat, or a store display. When the destination is unknown, treat
   it as a screen. Offer a 5-second motion version made from this poster, per
   [animating a delivered image](animate-a-delivered-image.md).

A poster made only for print or slides (an exhibition board, a printed banner,
a slide cover or background), a poster that is only text, or a plain
background gets no offer: a moving version has nowhere to be shown or nothing
to move.
