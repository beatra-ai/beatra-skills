# Writing the brief

The brief is the deliverable. It is written from a Douyin post, comments, or keyword
results that were looked up or pasted. It is never written from typical clip stats.

## Four blocks

1. **What the clip or keyword is doing.** Play, like, and comment only when a lookup
   returned them or the user supplied them. A looked-up count carries its read time; a
   missing count is missing.
2. **The hook.** The opening line or opening move, quoted from the caption or from
   what the user pasted. Do not polish it into a new script while presenting it as
   theirs.
3. **A verbatim comment.** Keep the audience's wording. If no comment was looked up or
   pasted, say comments are missing rather than inventing one.
4. **Follow-or-not.** A call, with the counts, the hook, and the comment as the
   reasons. This is inference. Mark it as inference and give the evidence.

One revision of the wording is free. Regenerating the brief from the same evidence is
free. A new lookup is not.

## Provenance

- A figure or line read from a lookup is marked as looked up, with the date it was
  read.
- A figure or line the user supplied stays marked as supplied.
- A missing figure is stated as missing. It is never estimated, interpolated, or
  carried in from what similar posts usually look like.
- Why a clip performed well remains inference. Mark it as inference, give the
  evidence, and say what would confirm it.
