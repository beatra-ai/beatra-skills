# Episode script

## Start from supplied material

This workflow turns an article, notes, an outline, or a finished script that
the user already has into a single-host episode. Reuse material and show
decisions already present in the conversation before asking for more.

If the request provides only a topic, ask for the article, notes, outline, or
finished script before drafting. Do not fill a missing source with invented
facts, opinions, statistics, quotations, examples, or positions. Every fact,
opinion, and number in the spoken script must trace to the supplied material
or to a user-approved edit.

## Set the listener focus

Use the intended listener from the show profile when one exists. If the source
could credibly become different episodes for different listeners, ask which
listener and takeaway should guide the spoken emphasis. Otherwise infer one
short episode focus from the supplied material and mark it for approval with
the draft. A listener focus can change ordering, transitions, and how much
context the host gives; it never authorizes new facts, claims, examples, or
positions.

## Make prose easy to hear

Preserve the meaning while adapting the material for a listener:

- split long written sentences into short, natural spoken thoughts;
- replace page-only constructions with spoken phrasing;
- write numbers, dates, units, URLs, citations, and abbreviations in the form
  the host should say aloud;
- add a short transition wherever the listener needs the connection between
  sections; and
- shape the user's material into an opening hook, a clear sequence of sections,
  and the show's recurring closer when it has one.

Names, terms, figures, and stated positions stay intact unless the user
approves a change. A target duration is a review goal rather than a promise:
the returned audio duration is authoritative.

## Approve the spoken draft

Present the listener focus and episode script section by section. Confirm the
title, opening, closer, substantive claims, and any pronunciations that affect
the read before proposing paid synthesis. When the user wants only a speakable
script, stop at the approved script and create no audio.

Build a pronunciation list for proper nouns, foreign words, acronyms, and
polyphonic characters. Record each written term and the spoken form the user
confirms, then carry it forward in the show profile.

Keep one synthesis input at or below 50,000 characters. For material above
that limit, split only at a topic or section boundary; never split a sentence
or force a listener through an abrupt cut.
