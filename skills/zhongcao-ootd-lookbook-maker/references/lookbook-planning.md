# Lookbook planning

Build the creative brief before preparing a paid request. A good REDnote OOTD
lookbook feels like one fashion story, not a set of unrelated outfit images.

## Build the lookbook card

Capture only facts and decisions that help the creator publish the requested
story:

```text
Outfit anchor: source photo role or described garments
Must-keeps: silhouette / layer order / colors / patterns / material / accessories
Occasion: commute / date / travel / cafe / event / seasonal moment
Audience: personal followers / styling community / brand audience
Story angle: fashion diary / outfit breakdown / styling tip / favorite piece
Visual direction: editorial / relaxed street style / soft vintage / clean minimal / playful color
Palette and light: shared set direction
Title-safe placement: top / side / lower third
References in order: outfit first, then mood / scene / composition guides
```

Reuse all known context. A clear outfit photo or a concrete styling idea is
enough to propose the default sequence. Ask one compact question only when the
missing outfit, occasion, or visual direction would change the result.

## Choose a story angle

| Angle | What the carousel should make clear | Caption direction |
| --- | --- | --- |
| Daily OOTD | What made this outfit feel right today | Start with the moment, then name the styling move |
| Outfit breakdown | How garments and accessories work together | Lead with the color, proportion, layer, or texture rule |
| Favorite piece | Why one item earns its place in the look | Introduce the item, show it in context, then share the pairing |
| Seasonal idea | How the look suits a place, weather, or occasion | Name the setting and give the audience an easy styling takeaway |
| Brand seeding | How the product fits a real fashion moment | Keep the garment visible, show the styling context, and use the brand facts supplied by the user |

## Keep the sequence coherent

Carry three anchors through all slides:

- **Outfit anchor:** the same confirmed garment details, layer order, and
  accessories remain legible across the sequence.
- **Visual anchor:** palette, light, and setting belong to the same editorial
  family.
- **Narrative anchor:** each slide advances the same moment rather than
  repeating the cover.

Use clean title space on the cover and keep any embedded display text minimal.
Prepare title and caption language as separate post copy so the creator can
choose their final wording.

## Draft the post package

Create a concise, original package aligned with the selected story angle:

1. Three title directions: a mood-led option, a styling-detail option, and an
   audience-value option.
2. A short caption outline: opening hook, outfit detail, scene or feeling,
   practical styling takeaway, and invitation to save or discuss.
3. A selective tag set: core style, occasion, garment or material, and one
   REDnote discovery term that the user already uses naturally.

The image set and post package should name only user-confirmed product or brand
facts. Keep claims, prices, and availability tied to the user's supplied
details.
