# Writing the script

The script is the deliverable. It is written from captions that were looked up or
from a transcript the user pasted. It is never written from a guessed spoken track.

## Two blocks

1. **Chinese spoken script.** Spoken lines a host can say, in Chinese, following the
   original's beats. Keep claims, numbers, and names that the captions or paste
   actually contain. Do not add a fact the source did not say. Mark inference as
   inference.
2. **Remake structure.** The opening, the moves in order, and the close, each tied to
   a caption or transcript span that prompted it. This is a structure for a remake,
   not a produced video.

One revision of the wording is free. Regenerating the script from the same captions
or transcript is free. A new lookup is not.

## Provenance

- A line read from a lookup is marked as looked up, with the date it was
  read.
- A line the user supplied stays marked as supplied.
- A missing transcript is stated as missing. It is never estimated, interpolated, or
  filled in from what similar videos usually say.
- Why a beat should be kept remains inference. Mark it as inference, give the
  evidence, and say what would confirm it.
