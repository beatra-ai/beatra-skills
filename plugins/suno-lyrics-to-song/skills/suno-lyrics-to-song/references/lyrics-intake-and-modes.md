# Lyrics intake and modes

## Accepted starting material

The starting point must be lyric material already supplied by the user or already
visible in the conversation:

- complete existing lyrics;
- a verse, chorus, or other lyric draft;
- loose lines intended as lyrics;
- an existing hook that needs supporting structure.

When the user brings only a topic, mood, story brief, or title, ask them for one lyric
line or hook to anchor this lyrics-to-song workflow. That is the only missing creative
input required before work can begin.

## Preserve mode

Use Preserve by default when the user asks to arrange, compose, generate, or make a
song from supplied lyrics without asking to change the lyric text. Do not interrupt
the workflow with a Preserve-or-Optimize question.

Treat each supplied lyric line as an immutable unit.

- Preserve every character, punctuation mark, spelling choice, capitalization choice,
  and whitespace within each lyric line.
- Preserve every complete lyric line and its exact position in the supplied line
  sequence; do not split, merge, paraphrase, correct, shorten, add, or reorder
  lyric-body text.
- Only adjust surrounding line breaks or blank-line spacing to mark section
  boundaries. Never use this formatting permission to change any complete lyric
  line's content or order.
- Add section labels such as `[Verse]`, `[Chorus]`, or `[Bridge]` only outside the
  lyric-body lines. Labels are arrangement instructions, not new lyrics.
- When a refrain should repeat, include the repeated lines in the complete proposed
  version so the final production confirmation covers the exact lyric text.

Before confirmation, state whether surrounding line breaks or blank-line spacing were
adjusted and show the complete result so the user can compare it with the source.

## Optimize mode

A request to polish, rewrite, improve, or optimize grants permission to change the
lyric text. Otherwise remain in Preserve. Then optimize only what serves singability
and the intended song:

- balance line length and breath load;
- align natural word stress with rhythmic emphasis;
- remove awkward phrasing without changing intended meaning;
- strengthen rhythmic flow, rhyme, repetition, and recall;
- sharpen the hook and section contrast;
- shape verses, chorus, and bridge around one emotional progression.

Record every must-keep line before editing and preserve each one exactly, including its
characters and punctuation. Names, facts, quotations, and identity-sensitive wording
also remain fixed when the user marks them as fixed. If a must-keep line creates a
singability tradeoff, explain it rather than silently changing it.

Show the full revised lyric, not excerpts, and summarize material changes inside the
complete production card. Approval of that complete card both accepts the lyric and
authorizes one paid generation. When the user explicitly asks to review the lyric
first or says not to spend yet, show the revised lyric separately and stop before any
paid call.

## Structure checks

For either mode, confirm that the selected section order supports a clear emotional
arc; the hook arrives deliberately; repeated material has a purpose; line density is
plausible for the tempo feel; and labels stay short and conventional. Do not claim
that a written structure guarantees exact pronunciation, melody, duration, or casting.
