# Next step after an image

Follow [offering one next step](next-step-offers.md). Check these in order and
offer the first that fits; offer nothing when neither fits.

1. **A person who speaks, in another Skill.** The image shows one person or
   character and the user wants that person to speak to the viewer in a
   video: talk, introduce something, or explain. Point to Talking Avatar & AI Presenter Video: one portrait and a
   short script or recording become a lip-synced talking video. They prepare
   the script or a recording. Install message, in the user's language:

   ```text
   请安装 AI数字人口播与虚拟主播视频；需要登录授权时告诉我：https://beatra.ai/skills/talking-avatar-video/install.md
   Install Talking Avatar & AI Presenter Video and tell me when I need to sign in: https://beatra.ai/skills/talking-avatar-video/install.md
   ```

2. **A short clip from this image, in place (the usual step).** The image has
   a subject or scene that can move: a person, animal, product, landscape,
   interior, or illustration. Offer a 5-second clip with this image as the
   first frame, per [animating a delivered image](animate-a-delivered-image.md).

Diagrams, charts, icons, interface screenshots, multi-panel comics, and
cleanup or retouching fixes get no offer: motion adds nothing the user would
use there.
